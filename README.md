# AVS Solar Calculator

A static solar savings calculator for deployment on Vercel.

## Project structure

- `index.html` – entry page
- `assets/css/styles.css` – styling
- `assets/js/main.js` – calculator logic
- `vercel.json` – deployment config for static hosting

## Local preview

Open the project in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Keep the default settings for a static project.
4. Deploy.

No build step is required for this static site.
